# Telescope derivative

The original user-supplied `loyalty-brass-telescope.glb` remains in the repository root, unchanged. The runtime copy is `public/assets/loyalty-brass-telescope.glb`.

Run `prepare_telescope.py` with Blender in background mode. `LOYALTY_TELESCOPE_OUT` selects the output folder. The default is a temporary review folder, so regeneration does not overwrite the approved runtime asset. The script produces a GLB, a studio preview and compact provenance.

The derivative uses 12 percent decimation and embedded 1K textures. The model is decorative and does not represent a loyalty account or change saved balances. Its position is beside the forum, at scene coordinates 9, 0.02, 21 and 2.6 times source scale.

Source: Tripo free text-to-3D export supplied by Sammy. Generation page: https://studio.tripo3d.ai/workspace/generate/c7fe6c5a-fd82-4eef-9f8f-a07173e0804f.
